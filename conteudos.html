Os principais tópicos de Programação e Algoritmo

Algoritmos e Lógica

Um algoritmo descreve os passos de uma tarefa. Todo algoritmo tem entrada, processamento e saída.

# Entrada -> Processamento -> Saída
nome = input("Seu nome: ")
print("Bem-vindo,", nome)

Variáveis e Tipos

Variáveis guardam valores. Os tipos básicos são int (inteiro), float (decimal), str (texto) e bool (verdadeiro/falso).

idade = 17          # int
altura = 1.65       # float
nome = "Ana"        # str
maior = idade >= 18 # bool

Condicionais

Permitem tomar decisões: o programa executa um bloco ou outro conforme a condição.

nota = 8
if nota >= 7:
    print("Aprovado")
elif nota >= 5:
    print("Recuperação")
else:
    print("Reprovado")

Estruturas de Repetição

O for repete uma quantidade conhecida de vezes. O while repete enquanto uma condição for verdadeira.

for i in range(1, 6):
    print(i)

cont = 0
while cont < 3:
    cont += 1

Listas

Uma lista guarda vários valores em uma única variável, e cada item tem uma posição (índice) que começa em 0.

frutas = ["maçã", "uva", "pera"]
frutas.append("manga")
print(frutas[0])
print(len(frutas))

Funções

Funções organizam o código em blocos reutilizáveis, com parâmetros e retorno.

def dobro(n):
    return n * 2

print(dobro(4))   # 8
