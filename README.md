SITE: PROGRAMACAO E ALGORITMO (PYTHON)
======================================

COMO ABRIR
1. Extraia (descompacte) a pasta ZIP. Clique com o botao direito > "Extrair tudo".
2. Abra a pasta "site-pa".
3. De dois cliques em "index.html". O site abre no navegador.
4. Precisa de internet (o Bootstrap e os icones vem da internet).

IMPORTANTE: nao tire os arquivos de dentro da pasta.
Os HTML precisam das pastas css, js e imagens ao lado deles.

O QUE TEM DENTRO
index.html       -> Pagina inicial (carrossel, sobre, conteudos, exercicios)
sobre.html       -> Sobre a disciplina
conteudos.html   -> Conteudos de Python (com codigos)
exercicios.html  -> Questoes com correcao automatica
materiais.html   -> Videos, apostilas, sites e jogos
contato.html     -> Formulario de contato
css/estilo.css   -> Cores, tamanhos, espacos, grid e responsivo
js/script.js     -> Correcao dos exercicios e validacao do formulario
imagens/         -> 3 imagens do carrossel

O MENU (NAVBAR)
Esta no topo de todas as paginas. Clique em Inicio, Sobre, Conteudos,
Exercicios, Materiais ou Contato para trocar de pagina.
No celular, clique no botao "Menu".

COISAS PARA TROCAR ANTES DE ENTREGAR
- materiais.html: troque ID_DO_VIDEO pelo codigo de um video do YouTube.
- materiais.html: troque os links "#" das apostilas pelos seus PDFs.

COMO MUDAR AS CORES
Abra css/estilo.css e mude os valores no comeco, em ":root".
Paleta usada: #F3F2F1, #C7C7C9, #8B8D92, #B23A3A e #2B2C2F.
Fonte do site: Times New Roman.
